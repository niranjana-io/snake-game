# 🐍 Snake Game (Python)

A classic Snake game built using Python's Turtle graphics module.

## 🎮 Features

* Smooth snake movement with arrow key controls
* Randomized food spawning with color variation
* Score tracking with persistent high score (saved locally)
* Collision detection:

  * Wall collisions
  * Self (tail) collisions
* Automatic game reset on collision

## 🛠️ Tech Used

* Python
* Turtle Graphics
* Object-Oriented Programming (OOP)

## 📂 Project Structure

* `main.py` → Runs the game loop and handles input
* `snake.py` → Snake movement and behavior
* `food.py` → Food generation and randomness
* `scoreboard.py` → Score + high score logic
* `data.txt` → Stores high score

## ▶️ How to Run

1. Make sure Python is installed
2. Run the game:

```bash
python main.py
```
